Parte A

Diseño del recurso didáctico

Título

«Código Ciudadano: Laboratorio de Python»

Modalidad elegida: actividad interactiva tipo laboratorio. Programar se aprende ejecutando, fallando y corrigiendo; un laboratorio con retos cortos da retroalimentación inmediata y mantiene la motivación mejor que leer una guía.

Descripción

Cuaderno interactivo con retos progresivos para estudiantes de bachillerato sin experiencia previa. Cada módulo cierra con un «punto de ciudadanía» que conecta lo programado con una decisión ética real.

Objetivo general

Desarrollar programas sencillos en Python aplicando buenas prácticas de autoría, licencias, privacidad y uso responsable de la IA.

Objetivos específicos (Bloom)

  • Identificar tipos de datos y variables.
  • Aplicar operadores y condicionales para tomar decisiones.
  • Construir bucles que automaticen tareas.
  • Diseñar funciones reutilizables.
  • Organizar datos en listas y diccionarios.
  • Depurar errores con try/except.
  • Evaluar críticamente código de terceros y de IA.

Actividades prácticas progresivas

Reto 1 · Variables y entrada de datos 
# No pidas más datos de los necesarios
nombre = input("¿Cómo te llamas? ")
edad = int(input("¿Cuántos años tienes? "))
print(f"Hola, {nombre}. En 5 años tendrás {edad + 5}.")
Reto 2 · Condicionales 
nota = float(input("Nota (0-100): "))
if nota >= 90:
    print("Excelente")
elif nota >= 70:
    print("Aprobado")
else:
    print("A reforzar")
Reto 3 · Bucles y validación de contraseña 
while True:
    clave = input("Crea una contraseña: ")
    if len(clave) >= 12 and any(c.isdigit() for c in clave):
        print("Contraseña robusta ✔")
        break
    print("Mínimo 12 caracteres y un número.")
Reto 4 · Funciones, listas y diccionarios 
def promedio(notas):
    return sum(notas) / len(notas)

estudiante = {"alias": "Ada22", "notas": [85, 92, 78]}
print(f"{estudiante['alias']}: {promedio(estudiante['notas']):.1f}")
Reto 5 · Manejo de errores (proyecto final) 
try:
    n = int(input("Un número: "))
    print(100 / n)
except ValueError:
    print("Eso no es un número.")
except ZeroDivisionError:
    print("No se puede dividir entre cero.")

Parte B

Guía de ética y ciudadanía digital

El código también tiene dueño

El copyright protege automáticamente toda obra original, incluido el código. Las licencias Creative Commons indican qué puedes hacer con imágenes y textos (CC BY exige dar crédito). Cita siempre código, imágenes y recursos de terceros.

# Fuente: respuesta de @usuario en Stack Overflow
# https://stackoverflow.com/q/xxxx · licencia CC BY-SA 4.0
def invertir(texto): return texto[::-1]

Reto: pon crédito en cada fragmento ajeno que uses y anota si lo generó una IA.

Reutiliza con criterio

Antes de copiar de GitHub, Stack Overflow o una IA, lee la licencia, entiende el fragmento y adáptalo. Copiar sin comprender no es aprender.

# Reescribí la lógica con mis variables y la probé con 3 casos

Reto: explica en voz alta cada línea antes de entregar un código que no escribiste solo.

Libre, abierto o propietario

Software libre garantiza libertades de uso, estudio, copia y mejora. Open source enfatiza el código visible y colaborativo. Propietario restringe el acceso al código y su redistribución.

Reto: busca un programa de cada tipo que uses a diario y clasifícalo.

MIT, GPL, Apache y BSD

MIT/BSD: muy permisivas, solo piden conservar el aviso. Apache 2.0: permisiva y con concesión de patentes. GPL: si distribuyes una versión modificada, debe seguir siendo libre. Python usa la licencia PSF y la mayoría de sus librerías son abiertas.

pip show requests  # revisa el campo License

Reto: elige una licencia para tu proyecto final y justifícala en el README.

Tus datos no van al repositorio

Nunca publiques nombres reales, correos, teléfonos ni claves en foros, repositorios o notebooks públicos. Una vez en línea, es muy difícil borrarlos.

import os
api_key = os.getenv("MI_API_KEY")  # nunca escrita en el código

Reto: revisa un notebook tuyo y elimina cualquier dato personal antes de compartirlo.

Nube y contraseñas

En Colab o Replit, revisa quién puede ver tu cuaderno. Usa contraseñas largas y únicas, un gestor de contraseñas y verificación en dos pasos (2FA).

Reto: activa 2FA en tu cuenta de correo y de GitHub esta semana.

Tu huella digital

Cada commit, comentario y publicación forma tu reputación. Lo que compartes hoy puede verlo un futuro profesor o empleador. Comunícate con respeto en foros y GitHub: pregunta con claridad, agradece y no ridiculices.

Reto: busca tu nombre o alias en internet y evalúa qué imagen proyectas.

IA como copiloto, no como sustituto

Usa la IA para entender, depurar y practicar, no para entregar trabajo ajeno como propio. Declara cuándo la usaste y verifica siempre lo que genera.

# Prompt ético: «Explícame por qué falla este bucle,
# sin darme la solución completa»

Reto: en cada entrega agrega una nota: «Usé IA para… y verifiqué…».

Conclusión reflexiva

Escribir código es crear herramientas que otros usarán, y toda herramienta tiene consecuencias. Un buen programador no solo hace que el programa funcione: reconoce el trabajo ajeno, protege los datos de las personas, elige licencias con conciencia y usa la IA con honestidad. Aprender Python es aprender a pensar con lógica; la ciudadanía digital es aprender a decidir con responsabilidad. Juntas forman una misma competencia: programar para construir un entorno digital más justo, seguro y colaborativo.
